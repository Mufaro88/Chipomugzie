# Inbox — drop long-form here

Drop ONE long-form asset in this folder as a `.md` file (a YouTube script, a
transcript, an essay, a voice-memo dump). Then run the **repurpose** skill:

> "repurpose the newest file in inbox"

The output lands in `repurpose/<asset-name>/`, one file per platform, and the
dashboard updates.

Tip: to get content out of a Claude chat, just copy the text, paste it into a
new `.md` file here, and save. Plain markdown — no Word docs.
