# Voice — paste your past content here

To make everything sound like YOU, paste your existing content in here as `.md`
files, ideally grouped by platform:

```
voice/
├── youtube/     ← past video scripts / transcripts
├── x/           ← past tweets / threads
├── linkedin/    ← past posts
├── instagram/   ← past captions / reel scripts
└── newsletter/  ← past emails
```

One file per piece is fine, or paste several into one file — it doesn't matter.
Then run the **voice-analysis** skill and Claude writes your voice profile into
`context/brand-voice.md`.

The more real content you add here, the more the output sounds like you. If you
have content sitting in Claude chats, copy it out and drop it in here.
